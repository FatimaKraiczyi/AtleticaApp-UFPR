## Getting Started

### Installation

1. Clone the repository:

```bash
https://github.com/FatimaKraiczyi/AtleticaApp-UFPR.git

```

Go to 
```bash
cd AtleticaApp-UFPR
```


### Running the Application

#### Web

```bash
cd next
# Usando yarn
yarn install 
yarn dev

# Ou usando npm
npm install
npm run dev
```


#### Mobile (expo)

```bash
cd expo-app
yarn install
yarn expo start
```
