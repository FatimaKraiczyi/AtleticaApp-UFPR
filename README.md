## Getting Started

### Installation

1. Clone the repository:

```bash
https://github.com/FatimaKraiczyi/AtleticaApp-UFPR.git

```

Go to 
```bash
cd AtleticaApp-UFPR
```


### Running the Application

#### Expo

```bash
cd expo-app
yarn install
yarn expo start
```


#### Next.js

```bash
cd next
yarn install
yarn dev
```
